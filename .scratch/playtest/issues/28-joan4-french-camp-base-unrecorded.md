### Grilling (2026-10-26)

> *This was generated by AI during triage.*

**The camp, verified.** Read from `AP_Joan_4.aoe2scenario` with the vendored AoE2ScenarioParser,
read-only, by resolving each `CHANGE_OWNERSHIP` effect's area against the objects inside it:

| Trigger | Conditions | Effect |
|---|---|---|
| 34 `AP Set Scene` | none | `P5 -> P0`, area (9,48)-(30,77), no object filter |
| 42 `AP Give Base` | two | `P0 -> P1`, the same rectangle, no object filter |

P5 owns inside that rectangle: **Town Center 1, Mill 1, Lumber Camp 1, Mining Camp 1**, plus 4
Villager Male, 2 Villager Female, 2 Crossbowman, 3 pavilion decoratives and a flag. The units
already match `obtains_unit`; only the buildings are unrecorded. Pavilions are not members of
`Age2BuildingData`, so there is nothing to record for them.

`[S15] Joan gets TC` is a red herring despite the name: its effect carries
`object_list_unit_id=603` (`FLAG_D`), so it moves flags, not a Town Center. The camp reaches P1
only through `AP Give Base`.

**Joan 4's map**, for sizing the consequences: BASE holds gold 4000, stone 1400, herd 600, bush
1750; OPEN holds gold 6400, stone 1400, bush 625, shore fish 1425, deep fish 3950. So the standing
Mill and Mining Camp both open real routes - this is not a cosmetic record.

**The Lumber Camp is the big one.** It is a *seeded* building, so recording it standing makes
`_has_seeded_building` true without `LUMBER_CAMP_WOOD`, exactly as CONTEXT.md's Seed item entry
prescribes ("A building standing at the start asks for no seed item"). The item itself stays in
the pool: `ResourcePool.seeds` filters on options only, and `is_economy_route_shuffled` returns
`True` for the Lumber Camp unconditionally. Joan 4 simply stops needing it.

**Scope held to Joan 4.** A sweep of every scenario for unrecorded handovers was attempted and
**withdrawn**: it replayed ownership changes in trigger-list order and ignored conditions, which
produced a wrong answer for Genghis 2 and so cannot be trusted anywhere. The sound method is the
per-trigger read used above, one scenario at a time. No follow-up ticket was filed from it.

**Two separate defects came out of this grilling.** Genghis 2 recorded a standing Mill P1 never
receives - verified from the triggers, confirmed by the maintainer, and fixed on the spot by
deleting the line, no ticket. The other is [#30](30-standing-dropsite-charged-wood.md): a standing
non-seeded dropsite is still charged *some* wood. That one is kept out of #28 so this ticket's
answer movement stays attributable.
