## Report

> *This was generated by AI during triage.*

Some objects that an `AP Give ...` trigger hands to P1 start the scenario owned by another player.
Joan 2's dock is the case that surfaced it: it belongs to Burgundy (P2) on the map, so #26 had to
rule it as Burgundy's dock, but `AP Give Dock` makes it P1's.

Most of these are moved to Gaia at runtime by a **staging trigger** (`AP Set Scene`, `AP Set Stage`,
`AP Setup`, `AP Startup`) when the scenario starts, and only later given to P1. So the map, which the
scan and the player records read, still shows them as the original owner's.

The maintainer wants every object that an AP trigger converts to P1 placed under **Gaia** in the map
instead, with its **Capture Flag set to Never**. Gaia objects capture once by default
(`cCaptureFlagOnce`), so without the flag P1 could take them by walking up before the item arrives.

## Comments

### Grilling rulings (2026-10-28)

> *This was generated by AI during triage.*

- **Scope is "originally Gaia".** Only objects the vanilla campaign leaves to Gaia move back. What
  another player owns in vanilla stays that player's, which is why no player is emptied (Bleda, the
  Tayichi'uds, the Kipchaks and the Genghis 1 tribes keep everything) and the old whole-player
  question fell away. The vanilla map, not the trigger scan, decides.
- **AP triggers only.** Non-AP ownership changes to P1 are untouched; `Capture Orleans` keeps
  handing Orléans over (its AP copy dropped vanilla's flags-only filter, and that is left alone).
- **Staging is deleted**, not left as no-ops. Attila 1's P5 palisade staging is a bug: strictly
  vanilla.
- **Capture Flag Never (0)** everywhere, not Gaia Aggressive. Auto-Convert units are left alone.
- **No logic change**: the objects "never should have been counted for those players".
- **Tooling**: the maintainer re-saves the ten v1.58 files to v1.59 (Capture Flag is a v1.59
  field; the v1.58 format has no slot for it and no effect sets it at runtime). The rest is a
  one-off script.
- **Done** is a 1-to-1 diff against vanilla, not against the pre-script AP map. Deliberate AP
  differences: the Scythian troop (out of the ticket, "they are fine") and the stripped tributes.
  Everything else the diff found is restored: Attila 1's six P1 flags, Attila 2's 59 decorations
  and 53 terrain tiles.
- **Joan 5's King's Troop** is P5's in vanilla (a Transport Ship carrying a Scout Cavalry and a
  Militia), so it stays out; its handover is fine and needs no ticket.
- **Glossary**: *Scenario item* added to `CONTEXT.md`; "grant" is avoided.
