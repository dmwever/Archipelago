# 12: Build Fish Trap doesn't require a Fishing Ship

**Reported:** 2026-10-20, playtesting

**Status:** ready-for-agent

## Report

Build Fish Trap appears to be in logic without the Fishing Ship.

## Audit (from code)

In AoE2, Fish Traps are built by Fishing Ships, not villagers.

`ScenarioCanBuild.answer` (`logic/custom_logic/ScenarioQuestions.py:153-163`) treats every building
the same way: the building item, `scenario.has_builders()` (villagers + the Builder profession),
the building's age, its prerequisite (Dock, `locations/Buildings.py:87`) and, for water buildings,
`has_water_access()`. A Fish Trap is in `_WATER_BUILDINGS`, but nothing swaps the builder.

So the rule:

- **misses** the Fishing Ship: neither its unit items (Fishing Ship Line / Boat upgrade token /
  Dock unit item, depending on `unitsanity_items`) nor the wood to build one.
- **asks for** villagers and the Builder profession, which a Fish Trap doesn't need.

The global location (`Logic.can_build_location_anywhere`) and every rule that asks
`has_building(FISH_TRAP)` inherit this. That includes `ScenarioResourceLogic._work_fish_traps`,
but that one is saved by its own `can_crew_fishing_ships()`. The Build location and anything else
that only asks "is there a Fish Trap" are not.

The right check already exists: `ScenarioResourceLogic.can_crew_fishing_ships()` (`:157-166`),
which is Fishing Ship items, the ship's age, and wood for one. It doesn't check the scenario's
`excluded_units` or whether the civ trains Fishing Ships. That's harmless today, since the only
scenario excluding Fishing Ships (Genghis 6) also excludes the Fish Trap and the Dock, but it's worth
covering if the builder check moves over to it.

## Likely shape of a fix

In `ScenarioCanBuild`, use the Fishing Ship (`can_crew_fishing_ships()` or a structural version of
it) as the builder for `FISH_TRAP` instead of `has_builders()`.

## Agent Brief

> *This was generated by AI during triage.* Approved 2026-10-22.

**Category:** bug
**Summary:** A Fish Trap is built by a Fishing Ship, so `ScenarioCanBuild` must ask for Fishing Ships instead of villager builders

**Current behavior:**
`ScenarioCanBuild` answers every building the same way: the building item, `has_builders()`
(villagers, plus the Builder profession when professions are shuffled), the building's age, its
prerequisite and, for water buildings, `has_water_access()`. For the Fish Trap that means:

- no Fishing Ship is asked for, so `Build Fish Trap` and every `has_building(FISH_TRAP)` are in
  logic without any Fishing Ship item;
- villagers and the Builder profession are asked for, though neither can build a Fish Trap.

**Desired behavior:**
For `Age2BuildingData.FISH_TRAP`, the builder is the scenario's Fishing Ships, asked structurally:
`ScenarioResourceLogic.has_fishing_ships()` (the Fishing Ship unit items for the current
`unitsanity_items` mode, and the ship's age). It replaces `has_builders()` for the Fish Trap only.
Everything else in the answer stays: the Fish Trap item, Feudal Age, the Dock prerequisite and
water access. Every other building keeps `has_builders()`.

The builder does not pay: no wood for the ship (ADR-0002, prerequisites stay structural).
`describe()` and the explain output keep their current one-line form.

**Key interfaces:**
- `ScenarioCanBuild.answer(scenario)`: picks the builder per building; Fish Trap gets
  `scenario.economy.has_fishing_ships()`, all others `scenario.has_builders()`.
- `ScenarioResourceLogic.has_fishing_ships()`: reused as is.
- `ScenarioLogic.has_building` / `ScenarioBuildingLogic.can_build_building` and
  `Logic.can_build_location_anywhere`: unchanged; they inherit the fix.

**Acceptance criteria:**
- [ ] Regression test: Attila, Joan and Genghis enabled, Attila starting, default options. A state
      without `Fishing Ship Line` cannot reach `Build Fish Trap`; the full pool can.
- [ ] `Build Fish Trap`'s item dependencies include the Fishing Ship unit item(s) for the
      `unitsanity_items` mode under test.
- [ ] With professions shuffled (`shuffle_villager: include_professions`), `Build Fish Trap` is
      reachable without the Builder profession items, given Fishing Ship items, a Dock, Feudal Age
      and the Fish Trap item.
- [ ] Every other building's `ScenarioCanBuild` answer is unchanged (still asks `has_builders()`).
- [ ] Existing age2de tests pass (`AGEIPELAGO_PATH` set), and a fuzz run of the committed meta yaml
      shows no new fill failures.

**Out of scope:**
- `can_crew_fishing_ships()` and the fish-trap food rule `_work_fish_traps` (its Fishing Ship check
  is now redundant but harmless; leave it).
- Excluded-unit or civ checks on the Fishing Ship.
- Paying for buildings on the buildable path (#17).
- Starting Fishing Ships a scenario hands out.
- Any XS change.
